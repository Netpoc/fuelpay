## Workspace purpose

This is a fuelpay mvp implementation backend service. this service is to mimick the data of fuel consumption, refill, draining of 25kva -100kva diesel generators on a daily basis. The data will be include time, volume and gps co-ordinates 


## How to operate

- **Ask first.** Ask clarifying questions before starting a complex task; don't assume scope or intent.
- **Plan before executing.** Show your plan and steps before doing the work.
- **Be concise.** Prefer bullet points over paragraphs in reports and summaries.
- **Cite sources.** When doing research, cite where each claim comes from.


## Folder conventions & workflow model

The workspace is organized around three folders. Follow this model:

- **`workflows/`** — Plain-English recipe files. When asked to run or follow a workflow, read the relevant file here and follow its steps in order.
- **`output/`** — All finished deliverables (reports, drafts, analysis). Everything you produce for the user lands here.
- **`resources/`** — Reference docs and templates to draw on while working.

> Note: these folders may not all exist yet. Create the needed folder before writing into it.
